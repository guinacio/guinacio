An autonomous AI assistant that runs persistently on your machine. Monitors email and calendar, browses the web, maintains a layered memory stack (knowledge graph + vector store), executes scheduled jobs, and works on your codebase — all from the system tray.

Built on the Claude Agent SDK with MCP integrations for Google Workspace, browser automation, smart home control, and more.
